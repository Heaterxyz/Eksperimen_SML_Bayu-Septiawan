# Wine Quality Dataset - Eksperimen Machine Learning

## 📊 Deskripsi Project

Project ini melakukan eksplorasi dan preprocessing data Wine Quality dari UCI Machine Learning Repository.

## 📂 Struktur Folder

- `Eksperimen_Student.ipynb` - Notebook untuk eksplorasi dan eksperimen manual
- `automate_student.py` - Script untuk otomasi preprocessing
- `wine_quality.csv` - Dataset raw
- `wine_quality_preprocessing/` - Folder untuk hasil preprocessing
